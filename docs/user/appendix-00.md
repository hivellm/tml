# Appendix

The appendix contains quick-reference material for TML's reserved words,
operators, and built-in functions. These pages are intended for lookup rather
than learning — the main chapters provide the worked examples and conceptual
explanations that belong alongside each feature.

## Contents

- [A - Keywords](appendix-01-keywords.md) — All 57 reserved words, compile-time
  constants, and naming conventions
- [B - Operators](appendix-02-operators.md) — Every operator grouped by
  category, with a full precedence table
- [C - Builtin Functions](appendix-03-builtins.md) — Functions available in
  every TML program without an import
