# Resumo

Modelos de Linguagem de Grande Escala (LLMs) são cada vez mais utilizados como agentes de programação autônomos em engenharia de sistemas complexos, porém há poucos dados empíricos sobre como eles empregam ferramentas de depuração no desenvolvimento de compiladores. Apresentamos o primeiro estudo observacional do uso de ferramentas de depuração por LLMs durante o desenvolvimento orgânico de um compilador, coletando 3.251 invocações de ferramentas em 300 sessões ao longo de 30 dias por meio do Model Context Protocol (MCP). Nossa análise revela que os LLMs são predominantemente orientados a testes (52,7% das chamadas), subutilizam diagnósticos de representação intermediária (IR) (7,5%), e respondem de forma mensurável a intervenções comportamentais via prompt -- com a adoção de verificação de tipos crescendo de 8,8% para 25,3% em 10 dias após regras explícitas. Identificamos uma mudança estrutural do estilo "executar e observar" para "analisar e depois verificar" nas estratégias de depuração, impulsionada por engenharia de prompts e experiência no domínio. Esses resultados têm implicações para o design de ecossistemas de ferramentas MCP, engenharia de prompts para LLMs e o campo emergente de programação de sistemas assistida por LLMs.
