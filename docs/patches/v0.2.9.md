## Added (SIMD String Operations — core::str::simd)

### Transparent SIMD Integration
- `contains()`, `find()`, `is_ascii()` now auto-dispatch to SSE2 for strings ≥ 32 bytes
- Zero API change — users get 10x speedup automatically
- `simd_load_ptr[I8x16]` intrinsic for single-instruction 128-bit unaligned load

### Functions
| Function | SIMD | Scalar Fallback | Technique |
|----------|------|-----------------|-----------|
| `find_byte` | ✅ | ✅ | PCMPEQB + PMOVMSKB |
| `contains_fast` | ✅ | ✅ | First-byte SIMD scan + memcmp verify |
| `find_substr` | ✅ | ✅ | First-byte SIMD scan + memcmp verify |
| `count_byte` | ✅ | ✅ | PCMPEQB + bit-clear popcount |
| `is_ascii_fast` | ✅ | ✅ | AND 0x80 mask + MOVEMASK |

### Benchmark Results
| Operation | Size | SIMD | Scalar | Speedup |
|-----------|------|------|--------|---------|
| find_byte | 4KB | 620 ns | 7,299 ns | **11.7x** |
| contains | 4KB | 733 ns | 8,594 ns | **11.7x** |
| is_ascii | 16KB | 5,536 ns | 44,519 ns | **8.0x** |

## Fixed (Compiler — 7 Codegen Fixes)

### Generic Struct Type Instantiation
- `require_struct_instantiation` now searches GlobalASTCache as fallback when module registry doesn't have the struct
- Re-processes already-registered structs if type definition was never emitted
- Fixes "Cannot allocate unsized type" for types like `MaybeIter[I32]`, `ArcInner[T]`

### Method Return Type Substitution
- Parses mangled type name to extract concrete type args when `type_subs` is empty
- Fixes `Maybe[T]` → `Maybe[I32]` in generic method call return types

### Module Lookup for Library Generics
- `find_module_for_type` falls back to pending_generic_structs_, struct_decls_, env_.lookup_struct
- Library generic types get correct Itanium-style mangled names

### Bare Type Parameter Detection
- `contains_unresolved_generic` now checks `current_type_subs_` for `NamedType{"T"}` nodes
- Prevents `ArcInner__T` appearing in IR instead of `ArcInner__I32`

### Struct Field Access on Chained Builder Results
- `hir_builder.cpp` `get_expr_type()` now joins all path segments for `CallExpr` lookups
- Added `MethodCallExpr` handler to resolve return types from receiver type + method name
- Fixes: `extractvalue` with index -1 (4294967295) on `f.name` where `f = Foo::new().method()`

### Struct Parameter ABI Mismatch (Segfault Fix)
- Function definitions: ALL struct parameters now passed as `ptr` (not by-value)
- Call sites: ALL aggregate args spilled to alloca and passed as `ptr`
- Fixes: segfault when passing structs with `Str` fields to functions
- Matches Windows x64 ABI requirement (structs >8 bytes must be by-pointer)

### Response Builder Methods Return Str
- `Response::json()`, `html()`, `text()` now return `Str` directly (build+send inline)
- Enables `return res.json(data)` pattern without explicit `.send()`
