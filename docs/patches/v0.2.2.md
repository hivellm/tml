# TML v0.2.2 — 2026-03-22

## Summary

Performance and code quality release: Tracy profiler integration with 70+ instrumented zones, HTTP server reaching 183K req/s (32% faster than Node.js cluster mode), and 702 `lowlevel` blocks migrated to typed accessor functions across 25 files.

---

## Added (Tracy Profiler Integration)

- **Tracy profiler** — Real-time frame profiling at nanosecond resolution
- **`profiler::begin(zone)` / `profiler::end()`** — Zero-cost intrinsics in both AST and MIR codegen paths; no runtime overhead when `--profile` is not enabled
- **70+ instrumented zones** across:
  - Compiler pipeline: lexer, parser, type checker, HIR/MIR lowering, LLVM backend, MIR pass manager, query cache hits
  - Standard library hot paths: HTTP request handling, collections, I/O, option, cell, os, glob, math
- **`--profile` build flag** — `scripts\build.bat --profile` builds with Tracy support enabled

---

## Added (HTTP Performance)

- **183K req/s throughput** — Beats Node.js cluster mode by 32%; syscall-bound at 2 syscalls per request
- **Accept-per-worker architecture** — Each worker thread accepts its own connections, eliminating accept lock contention
- **HTTP pipelining groundwork** — Non-destructive method/path parsing for future HTTP/1.1 pipelining
- **Pipelining boundary fix** — Save/restore byte at request boundary prevents inter-request data corruption

---

## Changed (Code Quality — `lowlevel` Migration)

702 `lowlevel` blocks migrated across 25 files to typed accessor functions, reducing unsafe surface area:

- **HTTP module** — `shared_get`/`shared_set`, `node_get`/`node_set`, `table_read`/`table_write`, `rd()`/`wr()` byte accessors, `buf_hdr_get`/`buf_hdr_set`
- **Stream module** — `buffered.tml`, `pipe.tml` migrated to Buffer accessors
- **Runtime** — `multi_executor.tml`, `timer_wheel.tml` migrated to typed accessors
- **HTTP subsystems** — dispatch, router, parse, conn_pool, rate_limit, agent all migrated
