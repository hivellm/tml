# TML v0.2.11 — 2026-04-04

## Summary

Complete AI/ML library (`std::ia`) — tensor operations, automatic differentiation, neural network layers, optimizers, and training infrastructure. 34 source files, 140 tests across 29 test files.

---

## Highlights

- **Tensor Core** — `Tensor` type with Buffer-backed storage, 7 dtypes (F32/F64/I32/I64/Bool/U8/U32), NumPy-style broadcasting, contiguous layout
- **Autograd Engine** — tape-based reverse-mode autodiff with 17 gradient functions (arithmetic, matmul, activations, reductions, loss)
- **Neural Network Layers** — Linear, Embedding, Dropout, LayerNorm, RMSNorm, MultiHeadAttention, 8 activation functions, 5 loss functions
- **Optimizers** — SGD (momentum + weight decay), Adam/AdamW (bias-corrected moments), gradient clipping (by norm/value), 3 LR schedulers (cosine annealing, linear warmup, step decay)
- **Training Infrastructure** — Dataset, DataLoader (batching + shuffling), Checkpoint, training utilities

## Known Issues

- **F64x2.get() codegen bug** — `extractelement` generates `i64` index instead of `i32`. SIMD temporarily removed from element-wise ops, reductions, and Adam. Matmul SIMD works (uses only `.sum()`, `.add()`, `.mul()`)
- **Closure codegen bug** — lambda expressions (`do(x,y) { ... }`) don't emit in LLVM IR. All ops use explicit loops
- **`const` cross-module** — module-level constants don't resolve cross-module. Workaround: use functions returning the value
- **`base` reserved keyword** — cannot use as variable name
