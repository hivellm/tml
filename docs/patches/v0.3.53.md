## Runtime — adversarial allocator mode (`compiler/runtime/memory/mem.c`)

Two opt-in debug behaviors on the `mem_free` path, read once from the environment:

- `TML_ALLOC_POISON=1` — freed blocks are filled with `0xDD` before release, so
  use-after-free reads garbage deterministically instead of stale-but-valid data.
- `TML_ALLOC_QUARANTINE=N` — freed blocks are held in a FIFO quarantine of N
  entries before the real `free`; a second free of a quarantined block is a
  proven double-free: reported (`tml runtime: double free of %p detected by
  TML_ALLOC_QUARANTINE`) and aborted deterministically.

Zero overhead when unset (single cached-flag branch). Thread-safe (SRWLOCK /
pthread mutex). Poison size via `_msize`/`malloc_usable_size`/`malloc_size`.

## Tooling

- `scripts/determinism.sh` — runs a command or a corpus N times; pass-rate,
  exit-code histogram, `--min-pass` threshold, per-run timeout.
- `scripts/determinism-corpus.txt` — tracked repro corpus, two sections:
  **PRIMARY** = 5 pure-TML `@test` suites in `compiler/tests/determinism/`
  (F-002 hashmap/list shapes, phase24h partial-move enum, F-013 refcount
  cycles, UzDB-shaped churn), run as prebuilt ADR-004 exes; **LEGACY** =
  phase24 cc_driver repros (fixtures relocated out of the frozen compiler-tml
  tree to `compiler/tests/determinism/legacy-cc/`).
- `scripts/determinism-gate.sh` — regression gate with per-target baseline
  floors, adversarial mode ON; wired into the local pre-push hook (10 runs,
  `TML_SKIP_DETERMINISM=1` escape hatch). GitHub CI builds run `--ci` without
  full LLVM, so the local gate is the enforcement point.
- `scripts/determinism-selftest.sh` + `scripts/fixtures/double_free_probe.tml`
  — harness self-verification (3 checks).

## Baseline (×100 per target per mode — `docs/analysis/tml-table-analysis/07-determinism-baseline.md`)

- Pure-TML corpus: **5/5 targets 100/100** in both modes (regression sentinels).
- `essential.c`: **0/100** both modes; failure-mode split now tracked
  (SIGSEGV ×~70 / heap abort ×~30).
- `c_essential_repro.c`: **86/100 normal** (the historical ×30 "28/30" was
  flattering) and **98/100 adversarial** — quarantine converts read-after-free
  crashes into silent wrong data, so pass-rate gates must pair with
  checksum-validating tests (as the corpus does). Key input for phase26.

## Collateral findings

Authoring the 5 small corpus files surfaced **4 new checker/codegen divergence
specimens** (constructs passing `tml check` but failing compilation): chained
field access through `get_ref()`, K001 i32-vs-ptr on the two-step form,
module-composition-sensitive monomorphization, and derive-glue referencing
`Shared[I64]::duplicate` without queueing its instantiation. All recorded with
repros in `.rulebook/tasks/phase27a_codegen-k001-root-cause/tasks.md`.
