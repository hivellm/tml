# v0.3.59 — F-020 ref Migration Complete (phase26d wave 2)

**Date:** 2026-07-16 · **Branch:** `fix/era0-stabilization` · **ERA 0, Phase B (parallel)**

Completes the pass-by-value → `ref` migration from the memory-copy audit (F-020):
read-only owning-aggregate parameters become borrows, so callee drop-glue no longer
frees lists/buffers the caller still owns — closing the phase24b UAF class across
the stdlib and removing a hidden whole-aggregate copy per call. ~120 signature +
call-site edits (explicit `ref` required at call sites — verified convention).

## Migrated

- **BigInt** (wave 2b): all 12 single-param operators + `mod_pow`/`mod_inverse`;
  35 internal + 16 test call sites (4 temp-arg sites restructured with local
  bindings). Each `a.op(b)` previously copied the operand struct and aliased+freed
  the caller's `digits` List handle — hot in RSA/mod_pow loops.
- **str::join / concat_all** (wave 2a) + 6 call sites; ref-param pass-through works.
- **HashMap::extend_from, File::write_bytes / write_all_bytes** (wave 2a) + call sites.
- **events/reactive** (wave 2b): 4 promise combinators + `observable_from_list_i32`.
- **HTTP/2** (this patch): `h2_buf_append`/`h2_conn_append_buf` (accumulator UAF —
  the callee freed the caller's outbound buffer on return), the 10 `handle_*`
  payload handlers + `process_frame`, `h2_encode_frame_raw`/`h2_decode_settings`,
  12 src callers (incl. `ref frame.payload` field-access refs) + 37 test call
  sites. `controller::register_all`.

## Deliberate exceptions

- `H2Frame::new`/`data`: consuming constructors (store the payload into the struct)
  — correctly by-value; scope correction vs the original work-list.
- `console::table`: reverted — trips a pre-existing K001 (catalogued).
- Observable subject state-bags: interior-mutability semantics, excluded by design.

## Validation

Determinism gate 22/22 at floor (adversarial ON) after every cluster. Suites:
str_coverage, hashmap_extend, binary_io, events 9/9, observable 7/7, 6 of 9 h2
suites green. Nine failures encountered during verification were each proven
identical at HEAD (pre-existing) and catalogued in `scripts/known-failures.txt`:
arraylist, once_lock, sync_barrier, sync_isolation, console table, bigint,
replay_subject, h2_build_response/flow_control/connection_streams (K001 classes)
and mutex (X002). BigInt + 3 h2 suites therefore validate at the type/borrow level
only until phase27a fixes their pre-existing K001s.
