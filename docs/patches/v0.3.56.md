# v0.3.56 — Stdlib Copy-Hazard Sweep Wave 1 (phase26d)

**Date:** 2026-07-16 · **Branch:** `fix/era0-stabilization` · **ERA 0 Stabilization, Phase B (parallel)**

Library-level correctness fixes from the memory-copy audit
(`docs/analysis/tml-table-analysis/08-memory-copy-audit.md`) that are independent of
the ADR-009 model fix — three double-free/UAF classes closed without a compiler change.

## Fixes

- **F-017 `Arc::try_unwrap` double-free** (`lib/std/src/sync/arc.tml`): the value was
  moved out and the inner deallocated, but the `Arc` handle was never forgotten, so
  `Arc::drop` later ran on the freed allocation. Now takes `mut this`, nulls `this.ptr`
  after the CAS+dealloc, and `Arc::drop` guards on a null pointer.
- **F-017 `AnyValue::into_inner` double-free** (`lib/core/src/types/any.tml`): read the
  value and `dealloc`'d `this.data` but never nulled it, so `AnyValue::drop`
  (null-guarded) freed the same block again — the long-standing
  `STATUS_HEAP_CORRUPTION` that kept `any_into_inner.test.tml` stubbed as `BLOCKED`.
  Now takes `mut this` and nulls `this.data` on both the match and mismatch paths; the
  test is unblocked with real coverage.
- **F-018 `Sync[T]` safe read accessors** (`lib/core/src/alloc/sync.tml`): `Sync::get`
  was a raw bitwise copy with no safe alternative. Added `get_clone(this) -> T where
  T: Duplicate` (deep clone) and `get_ref(this) -> ref T` (borrow), plus the aliasing
  hazard docstring `Shared::get` already carries.
- **F-023 `try_unwrap` weak-ref safety** (`Shared` + `Sync`): `is_unique()` only checks
  `strong_count == 1`, but `try_unwrap` then freed the whole inner even with outstanding
  weak refs (from `downgrade`), dangling them. Now mirrors `decrement_count`: on
  strong→0, decrement the implicit weak and `mem_free` ONLY when `weak_count` also
  reaches 0; the value is moved out and the handle nulled. Outstanding `SharedWeak`/
  `SyncWeak` keep the inner alive and their `upgrade()` correctly observes strong==0.

## Notes

- `mcp__tml__check` false-negatives on `Sync::get_ref`/`Shared::get_ref` (reports the
  borrow-through-raw-pointer intrinsic as undefined) — the isolated-file checker lacks
  intrinsics the full build has; both compile and pass their borrow tests. Zero-copy
  IR verification of the borrow accessors is owned by phase26e.
- Wave 2 (F-020, the ~40-site pass-by-value → `ref` migration) is a separate follow-up.
