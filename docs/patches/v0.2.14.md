### String Interning (phase12b)

New `std::intern` module for efficient string deduplication:
- **`InternPool[T]`** — thread-safe intern pool with HashMap backing
- **`intern(s: Str) -> Str`** — returns interned copy, guaranteed unique pointer
- **Methods:** `len()`, `is_empty()`, `clear()`, `contains()`, `remove()`
- **Thread-safe:** Mutex-wrapped HashMap with weak reference tracking
- **Use case:** JSON keys, HTML attributes, compiler symbol tables
