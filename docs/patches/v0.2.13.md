# v0.2.13 — Optional Chaining, MCP Daemon, Native Lib Management

**Date:** 2026-04-05

## Highlights

- **`?.` optional chaining** — `parse(json)?.get_string("name")` propagates Nothing through method/field chains
- **`let-else` guard clause** — `let Just(x) = expr else { return }` eliminates nested `when` cascades
- **MCP daemon supervisor** — crash recovery, hot reload, stderr capture
- **Native lib management** — `tml install`, `--bundle`, NativeLibResolver 3-tier
- **MCP research infrastructure** — enhanced logging, analyze tool, session context

## Language Features

### Optional chaining (`?.`)
```tml
let name = parse(json_str)?.get_string("name")  // Maybe[Str]
let city = user?.address?.city                    // field chaining
```
- Lexer: `?.` tokenized as `QuestionDot`
- Parser: creates `MethodCallExpr`/`FieldExpr` with `optional_chain=true`
- Type checker: unwraps `Maybe[T]`, resolves on `T`, returns `Maybe[U]`
- Codegen: branches Just/Nothing, auto-flattens `Maybe[Maybe[T]]` → `Maybe[T]`

### let-else guard clause
```tml
let Just(name) = parse("hello") else { return }
println(name)  // flat, no nesting
```
- Fixed nullable Maybe GEP codegen bug
- Removed mandatory type annotation — infers from expression
- Works with `continue`, `return`, `break`

## Compiler

### MCP daemon (`tml_daemon.exe`)
- Stdio proxy between Claude Code and `tml_mcp.exe` subprocess
- Auto-restarts subprocess on crash with JSON-RPC error response
- Captures subprocess stderr and includes in error message
- Fire-and-forget for notifications (no "id" field)
- `.mcp.json` uses daemon instead of direct MCP server

### MCP enhanced logging
- Test results, error classification, preceded_by tool tracking
- Session context: task ID, model, CLAUDE.md hash
- Session end summary: tools_used, error_rate, dominant_tool
- `mcp__tml__analyze` tool for inline research queries

### Native library management (NativeLibResolver)
- 3-tier resolution: project-local → user cache → compiler-bundled → vcpkg
- `tml install` — copies native libs to `~/.tml/native-cache/`
- `--bundle` flag — creates self-contained distributable with all DLLs
- `build.tml` support in test runner for external packages
- Platform detection: `platform.hpp/cpp` with OS/arch/extensions
