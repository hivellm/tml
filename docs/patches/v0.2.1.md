# TML v0.2.1 — 2026-03-21

## Summary

Codegen quality release: 12 compiler bugs fixed covering generics, Pin dispatch, struct mutation, and MIR memory intrinsics. HTTP server gains full RFC compliance (chunked encoding, 100-continue, 405/501, idle timeout).

---

## Fixed (Compiler — Codegen)

- **Pin-through trait method dispatch** — 4 interconnected fixes: type checker unwraps `Pin[ref T]` to find trait methods on `T`; generic inference handles ref-wrapped bare generics; `method_impl` unwraps Pin receivers; static dispatch infers bare generics in ref params
- **Cross-module generic struct field resolution** — `lookup_struct` now follows re-export chains (matching `lookup_enum`). Fixed `Ready[I32].value` resolving as `()` instead of `Maybe[I32]`
- **Range struct type declaration** — MIR codegen emits struct type definitions for library structs used in `StructInitInst` (e.g., `Range[T]`)
- **`ptr_read`/`ptr_write` multi-field structs** — 4 fixes across pipeline: `type_params` registration, HIR generic substitution, MIR `type_args` propagation, codegen type resolution
- **Struct field mutation** — mutable struct alloca was dead code in `thir_mir_builder` (array fast-path returned before struct check)
- **Integer literal coercion in function pointer calls** — `f(42)` where `f: func(I64)` now emits `sext i32 → i64`
- **`Iterator::fold[B]` monomorphization** — method-level generic dispatch, type param inference, `GenericType` handling all fixed
- **`memcpy`/`memmove`/`memset` MIR handlers** — added codegen handlers and LLVM intrinsic declarations
- **`copy_nonoverlapping`/`copy`/`write_bytes`** — registered in type checker (had codegen handlers but no type registration)

---

## Fixed (HTTP Server)

- **`ServerResponse` Bool fields → I64** — fixes i1 struct layout corruption when structs are passed through function pointers, unblocking middleware hooks

---

## Added (HTTP Server — Phase 2+3 Complete)

- **Chunked transfer-encoding** (RFC 7230 §4.1) — `decode_chunked`, `encode_chunk`, `recv_chunked_body`, integrated into worker loop
- **`Expect: 100-continue`** — server sends `HTTP/1.1 100 Continue` before reading request body when client requests it
- **405 Method Not Allowed + `Allow` header** — probes all 7 method radix trees and returns the allowed methods list
- **501 Not Implemented** — returned for unrecognized HTTP methods
- **URL percent-decoding** — verified already implemented; 14 tests added for coverage
- **`Date` header** — 404/501 responses now include RFC 7231 `Date` header via `app_build_response`
- **Idle timeout enforcement** — `SO_RCVTIMEO` on keep-alive connections prevents connection starvation
- **Middleware hooks re-enabled** — `onRequest`, `preHandler`, `onResponse` wired into `app_dispatch`
- **Custom error handler** — `onError` hooks called on 404 before default response

---

## Added (Core Library)

- **`Maybe::take()`** — consumes self, returns the inner value (mirrors Rust's `Option::take`)
- **`pub use` in `core::future`** — `Context`, `Poll`, `Ready`, `Pending` now publicly re-exported from the module
