# TML v0.2.6 — 2026-03-28

## Summary

The largest single release in the project: Phase 7 "Rust Parity Sprint" (16/16 tasks), 55 new compiler error codes, three new standard library data structures (BigInt, Trie, IntervalTree), a full core library reorganization into thematic directories, and a complete Rust-vs-TML gap analysis document.

---

## Added

### Collections

- **`List[T]` completeness** (phase7-01) — 15 new methods: `sort_by`, `binary_search`, `index_of`, `reserve`, `truncate`, `dedup`, `split_at`, `resize`, `fill`, `sort`, `insert`, `remove`, `contains`, `reverse`, `swap`. Iterator-based `collect()` support added alongside these.

- **`Iterator.collect()`** (phase7-02) — `FromIterator` behavior defined and implemented. All iterators now support `.collect()` to produce a `List[T]`. `ListIter::to_list()` alias retained for backward compatibility. `HashMap::from_iter` constructor added.

- **`HashMap` extras** (phase7-03) — 8 new methods: `is_empty`, `get_or_set`, `keys`, `values`, `retain`, `drain_keys`, `drain_values`, `extend_from`.

- **`BTreeMap[K,V]` / `BTreeSet[T]` generics** (phase7-15) — Previously restricted to `I64` keys. Now fully generic. Range iterators added: `range`, `range_from`, `range_to`, `range_full`.

### Strings

- **`Str` completeness** (phase7-05) — 12 new functions: `split_once`, `rsplit_once`, `strip_prefix`, `strip_suffix`, `splitn`, `is_ascii`, `eq_ignore_ascii_case`, `rsplit`, `replacen`, `trim_matches`, `matches`, `bytes`.

### File I/O

- **File I/O completeness** (phase7-06) — Binary read/write via `read_bytes`/`write_bytes`. `DirEntry` type for directory entries. `read_dir` iterator for listing directories. `remove_all` for recursive deletion. `FileMetadata` struct and `metadata()` function.

### Concurrency

- **Bounded channels** (phase7-07) — `sync_channel(capacity)` returns `(SyncSender[T], Receiver[T])`. `TrySendError` enum for non-blocking send failures. `Iterator` behavior implemented for `Receiver[T]` to consume all pending messages.

- **Thread completeness** (phase7-11) — Real `park`/`unpark` using Windows Event objects (previously spin-wait). `spawn_fn`/`spawn_i64` thread factory functions. `panicking()` query to detect if current thread is unwinding. `JoinHandle::detach()` to detach without joining.

### Environment

- **`std::env` module** (phase7-04) — `get_var`, `set_var`, `remove_var`, `current_dir`, `temp_dir`, `args`. Full FFI bindings to OS `getenv`/`setenv`/`getcwd`.

### Core Types

- **`Maybe[T]` extras** (phase7-08) — `is_just_and`, `get_or_insert`, `replace`, `unzip`.

- **`Bool` utilities** (phase7-10) — `then_some` and `then_with` standalone functions.

- **`core::prelude`** (phase7-10) — `lib/core/src/prelude.tml` with re-exports of the most-used types: `Maybe`, `Outcome`, `List`, `HashMap`, `Str`, `Text`, `Iterator`, `Display`, `Debug`, `Clone`, `Eq`, `Ord`, `Hash`, `Default`.

### Networking

- **Net extras** (phase7-12) — `TcpListener::incoming()` iterator for accept loops. `write_all()` and `read_to_string()` convenience methods on `TcpStream`.

### I/O Behaviors

- **`core::io` behaviors** (phase7-13) — `Read`, `Write`, `BufRead` behaviors defined in `lib/core/src/io.tml`. The stream and file modules now implement these shared traits, enabling generic code over any readable/writable source.

- **ASCII classification** (phase7-13) — 10 functions in `core::ascii`: `is_ascii_alphabetic`, `is_ascii_digit`, `is_ascii_alphanumeric`, `is_ascii_uppercase`, `is_ascii_lowercase`, `is_ascii_punctuation`, `is_ascii_whitespace`, `is_ascii_control`, `is_ascii_graphic`, `is_ascii_hexdigit`.

- **`core::random` trait** (phase7-13) — `Random` behavior defined in `lib/core/src/random.tml`. `std::random::Rng` implements it.

### Memory and Smart Pointers

- **Weak pointer extras** (phase7-14) — `SharedWeak[T]` and `SyncWeak[T]` types with `downgrade`/`upgrade` conversions. `ptr_eq` for pointer identity comparison.

- **Cell extras** (phase7-14) — `Cell::update`, `into_inner`, `replace_with`, `swap`, `get_or_init`.

- **Pin extras** (phase7-14) — `Pin::into_inner`, `as_ref`, `as_mut`, `set`.

### Iterator Extras

- **`is_sorted` / `is_sorted_by`** (phase7-09) — Available on all iterators.

### Compiler Features

- **Pre-condition runtime assertions** — `pre: expr` contracts in function signatures now emit `if (!cond) panic(msg)` at function entry. Type checker validates that contract expressions return `Bool` and reports error T090 on violation.

- **`impl_count[T]()` / `impl_name[T](index)` intrinsics** — Query which behaviors a type implements at compile time without reflection.

- **Compile-time field index validation** — `field_name[T](N)`, `field_type_id[T](N)`, `field_offset[T](N)` now emit error R001 when N exceeds the field count instead of silently returning garbage.

- **MCP `emit-ir` rewrite** — Changed from subprocess invocation (8s timeout, frequent "Connection closed" errors) to in-process `LLVMIRGen::generate()` (sub-second). The MCP `emit-ir` tool is now reliable for interactive use.

### Error Codes (Phase 0 — 55/55 complete)

- **55 new compiler error codes** fully implemented: T-series (type errors), R-series (reflection errors), B-series (borrow checker errors), L-series (lowlevel errors). Every code has a message, a plain-English explanation, and a recovery hint accessible via `tml explain <code>`.

### Standard Library Data Structures

- **`std::bigint::BigInt`** — Arbitrary-precision integers using base-10^9 limbs. Operations: add, sub, mul, div, rem, pow, gcd, mod_pow, mod_inverse, is_probably_prime (Miller-Rabin), bitand/bitor/bitxor, shift_left/shift_right, bit_length, to_hex, from_str. 26 tests.

- **`std::collections::Trie[V]`** — String-keyed prefix tree with flat-array layout. Methods: insert, get, contains, remove, starts_with, longest_prefix, keys_with_prefix, autocomplete. 10 tests.

- **`std::collections::IntervalTree[V]`** — Augmented BST with max-endpoint tracking. Methods: query_point, query_range, query_point_values, contains, all_intervals. 9 tests.

### File Seeking

- **`impl Seek for File`** — File seeking via `file_seek_from` C FFI wrapper around `fseek`/`ftell`.

### Reflection Testing

- **Reflection vtable dispatch tests** — `dynamic_dispatch.test.tml` (5 tests) validates that slot-based virtual method calls via the reflection system produce results identical to direct calls.

- **Reflection benchmark** — Measured overhead: debug builds 2ns/call direct vs 5.5ns/call reflected; release builds ~0ns both (optimizer inlines).

## Changed

### Project Structure

- **Core library reorganized** — 30 loose files moved into 6 thematic directories:
  - `data/` — arena, bitset, cache, pool, ringbuf, soo, collections
  - `types/` — option/Maybe, result/Outcome, tuple, range, any
  - `traits/` — clone, cmp, convert, default, borrow, hash, marker
  - `async/` — async_iter, task
  - `runtime/` — error, panic, hint, mem, pin, intrinsics, profiler
  - `reflect/` — reflect/mod.tml

- **Std library reorganized** — 9 loose files moved into thematic directories:
  - New directories: `math/`, `time/`, `debug/`, `events/`
  - Moved: `glob` into `file/`, `url`/`mime` into `net/`

- **12 single-`mod.tml` directories flattened** to standalone files. Affected: `async_iter`, `bstr`, `panic`, `task` (core); `observable`, `promise`, `debug`, `math` (std); `bench`, `coverage`, `report`, `runner` (test).
