# v0.3.81 — phase26e: collection borrow accessors — the zero-cost enabler (F-021 closed)

**Date:** 2026-07-19
**Task:** `phase26e_collection-borrow-accessors`
**Branch:** `fix/era0-stabilization`
**Commits:** `02781659` (Cluster A), `5b7b8270` (B+C), `e3e4fe81` (D), `84e3507e` (E+F+G) + closing docs.

F-021 (08-memory-copy-audit): TML collections had NO working borrowing
accessor — every read of a handle-bearing element deep-cloned. This phase
delivers the borrow API that turns "correct + leak-free" (phase26b) into
"zero-cost", with Rust-parity IR evidence
(`docs/analysis/tml-table-analysis/09-borrow-accessors-perf.md`).

## Cluster A — codegen foundations (C++)

- Three referenced-but-never-implemented intrinsics made real (each
  previously fell into the silent-i32-default hole): `list_get_mut`
  (List-header pointer math → element ptr, pure GEP), `ptr_as_ref[T]` /
  `ptr_as_mut[T]` (inttoptr). AST path, matching the slice-intrinsic model.
- **IndexMut works end-to-end** (`list[i] = v`): the "index_mut returns ()"
  blocker was a type-checker bug — `check_index` only handled Array/Slice;
  now resolves the element type from the `index`/`index_mut` impl. New
  codegen routing desugars `container[idx]` read/assign into method calls.
- C027 fixed for ref-returning calls (`x.get_ref().field` — phase27a Class
  6a): the CallExpr field-access branch now unwraps `RefType`/`PtrType`.
  Two-step (`let b = x.get_ref(); b.field`) verified already working at HEAD.
- Fixed a latent v0.3.80 `gen_structural_duplicate` bug (interleaved nested
  defines; library-handle fields bitwise-synthesized instead of queueing the
  real `duplicate`).
- Un-stubbed blocked tests: `non_null_refs` (as_ref/as_mut), `list_index_mut`.

## Clusters B+C — accessors (pure TML)

`List::get_ref(i) -> ref T` / `get_mut(i) -> mut ref T`;
`HashMap::get_ref(k) -> Maybe[ref V]` / `get_mut -> Maybe[mut ref V]`
(`Maybe[ref V]` verified end-to-end before adoption);
`BTreeMap::get_ref/get_mut` (via `find_index` → values);
`Deque::get_ref/get_mut` (ring-slot math). IR-verified zero-copy (GEP + ptr
return; no aggregate alloca/memcpy/duplicate). Refcount-probe tests prove
`get_ref` never bumps nested `Shared` handles (by-value `get` does, by
design). Docstrings state the invalidation contract.

## Cluster D — interior-ref borrow checking + type-shadow fix (C++)

- The NLL checker now binds a ref-returning method's result to the receiver
  borrow (narrow confident-only method resolution; NLL extends to last use).
  Conflicting interior refs — two `mut ref`s, or `mut ref` while a shared
  ref is live — are **B009 compile errors**. Blast-radius sweep: ZERO new
  borrow errors across the corpus. Negative fixtures live in
  `scripts/fixtures/borrow/` exercised by
  `compiler/tests/cli/borrow_interior_ref.sh` (2/2 reject).
- Residual (re-scoped, user decision): push-class invalidation
  (`get_ref` then `push`) is uncatchable while mutators are `this` — a
  `mut this` flip breaks 20+ std tests (immutable-binding mutation is
  idiomatic today). Filed `phase26g_collection-mutator-mut-this`; the
  wiring activates per-method the moment mutators require unique access.
- D0: `CodegenLibraryState` bare-name struct-layout collision fixed — a
  local `type Row` silently inherited `std::sqlite::Row`'s layout under the
  shared-stdlib restore (K001/field corruption); local definitions now
  shadow restored library layouts.

## Clusters E+F+G — iterators, hot sites, Text (pure TML)

- `List::iter_ref()` (`Item = ref T`) + `HashMapIter::value_ref()`. F-019
  resolved pragmatically: by-value iterators stay documented clone-read;
  the ref forms are the zero-cost opt-in. Deque keeps `get_ref(i)`
  (bespoke ring iterator not warranted); BTreeMapIter documented snapshot.
- Hot sites migrated to borrow reads: List `contains`/`index_of`/
  `binary_search`/`dedup`/`_quicksort` compares, `_quicksort_by` via
  `cmp(get_ref, ref pivot)`, BTreeMap `find_index` (was O(log n) key clones
  per lookup), `HashMap::duplicate` (2 clones → 1). Element moves stay value
  copies. Note: `ref` operands do NOT auto-deref in binary ops — explicit
  `*get_ref(i)` is the pattern.
- `Text::as_str_ref -> Str`: zero-copy borrow of the internal buffer for
  heap-backed Text (storage proven NUL-terminated in place); inline/SSO
  falls back to allocating `as_str`. `concat`/`concat_str` double-copy
  killed (single alloc straight into the result; inline path packs SSO
  words with zero alloc).
