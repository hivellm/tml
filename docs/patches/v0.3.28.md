## Performance: 4.4× Faster Cold Check

**Root cause:** `generate_all_meta_from_source()` parsed 418 library `.tml` files
on every compiler invocation but never wrote the results to disk.

**Fix:** After generating each module's metadata, serialize it via
`ModuleBinaryWriter::write_module()` to `.tml.meta` binary files.
On subsequent runs, the binary cache is loaded instead of re-parsing source.

| Metric | Before | After |
|--------|--------|-------|
| `tml check hello.tml` | 3.0s | **0.68s** |
| Meta files on disk | 0 | 405 |
| Speedup | — | **4.4×** |

## Compiler Fixes

- **Module discovery:** Added `pub mod protobuf` and `pub mod msgpack` to
  `lib/std/src/mod.tml` — meta preload now discovers all protobuf/msgpack
  submodules (was 418, now 433 modules)

- **Impl method visibility:** Non-public methods on non-generic impl blocks
  are skipped by the module loader. All proto_parser impl methods now have
  `pub` keyword.

- **Allocator attributes:** `mem_alloc`, `mem_free`, `malloc`, `free` now have
  `noalias`, `allocsize`, `allockind("alloc,uninitialized")`,
  `"alloc-family"="malloc"` for LLVM alias analysis and HeapToStack.

- **@inline on Heap methods:** `Heap::new`, `Heap::get`, `Heap::drop` marked
  `@inline` for LLVM to see malloc/free pairs after inlining.

- **Encoding benchmark fix:** Added `free_str()` to free returned strings in
  encode/decode loops (200K leaks → 0).

- **Drop/RAII confirmed:** `Drop` behavior + scope-exit drop insertion already
  fully implemented in AST codegen (`compiler/src/codegen/llvm/core/drop.cpp`).
