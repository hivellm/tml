# v0.3.85 — compiler-tml excluded from all tooling + TOML parser array-comment hang fix

**Date:** 2026-07-20

## compiler-tml temporarily excluded from everything (era0 stabilization)

`compiler-tml/` is frozen by strategic decision during era0 stabilization, but it was
still being mapped by every discovery surface (package registry, test-suite enumeration,
docs index, coverage). It is now excluded:

- **`tml.toml`** — removed `"compiler-tml"` from `[workspace] members`. This is the
  single lever: package discovery, `tml test` suite enumeration, docs generation, and
  coverage all derive from workspace members. A comment above the array documents how
  to re-enable.
- **`scripts/determinism-corpus.txt`** — the entire LEGACY section (12 `tml cc` repros
  routed through the frozen compiler-tml C frontend) is commented out with a re-enable
  note. The primary pure-TML corpus is untouched.
- **`docs/docs.json`** — regenerated (599 modules, zero `compiler-tml`/`compiler::`
  entries), so `docs_search`/`tml doc` no longer surface frozen symbols.

Building compiler-tml explicitly by path (`tml build compiler-tml/...`) still works —
it has its own `tml.toml`. Nothing outside `compiler-tml/` imports `compiler::`
(verified by sweep), so no consumer breaks.

**Re-enable when self-hosting resumes:** re-add the workspace member, uncomment the
corpus block, regenerate `docs/docs.json`.

## SimpleTomlParser: infinite loop on comments inside arrays (FIXED)

Found while making the change above: `SimpleTomlParser::parse_string_array()`
(`compiler/src/cli/builder/build_config.cpp`) consumed only whitespace, strings, and
commas inside `[...]`. A `#` comment inside an array — valid TOML — made `peek()`
stall on `#` forever: **the compiler hung with no error on any command** that loads
the manifest (reproduced: `tml check` hung >300 s; MCP daemon crash on startup).

Fix: the array loop now calls `skip_comment()` alongside `skip_whitespace()`, plus a
no-progress guard that turns any other unconsumable character into a parse error
("Unexpected character in array") instead of a hang.

**Gate:** in-array-comment probe manifest parses instantly (was: infinite hang);
`tml check` on `lib/std` green; `core/hash` 14/14 via the full MCP/daemon stack;
test discovery enumerates 177 suites with zero compiler-tml entries.
