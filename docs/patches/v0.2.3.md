# TML v0.2.3 — 2026-03-25

## Summary

Major stdlib expansion: panic recovery, compiler optimization hints, type-safe C FFI types, advanced collection primitives, and project-wide task restructuring. 8 tasks completed and archived.

---

## Added (Core Library)

- **Panic Recovery** (`core::panic`)
  - `PanicInfo` struct — message, file, line, column fields
  - `set_hook(fn_ptr)` / `clear_hook()` — install custom panic handler called before crash
  - `catch_unwind_fn(fn_ptr) -> CatchResult` — catch panics via setjmp/longjmp
  - `resume_unwind(msg)` — re-panic after catching
  - `CatchResult` enum: `Ok` | `Panicked(Str)`
  - C runtime: `tml_set_panic_hook`, `tml_catch_unwind_fn`, hook call wired into `panic()`

- **Compiler Hints** (`core::hint`) — optimization directives with zero runtime overhead
  - `unreachable_unchecked()` — emits LLVM `unreachable` instruction
  - `black_box_i64/bool/f64()` — inline asm memory clobber (prevents constant folding in benchmarks)
  - `spin_loop_hint()` — emits x86 PAUSE instruction for busy-wait loops
  - `likely(Bool)` / `unlikely(Bool)` — branch prediction hints via `@llvm.expect.i1`
  - `assume(Bool)` — `@llvm.assume` for optimizer assertions

- **Core FFI types** (`core::ffi`) — Type-safe C interop wrappers
  - Integer: `c_void`, `c_int`, `c_uint`, `c_long`, `c_ulong`, `c_longlong`, `c_ulonglong`
  - Float: `c_float`, `c_double`
  - Platform-sized: `c_size_t`, `c_ssize_t`, `c_ptrdiff_t`, `c_intptr_t`, `c_uintptr_t`
  - `c_long_bits()`, `c_long_max()` — platform-aware (32 on Windows, 64 on Unix)
  - `CStr` — borrowed C string wrapper: `from_ptr`, `to_str`, `to_owned_str`, `len`, `is_empty`, `byte_at`

---

## Added (Standard Library)

- **`CString` Drop** (`std::ffi::cstring`) — `impl Drop for CString` now correctly frees heap memory
- **`BinaryHeap` advanced methods** (`std::collections::binary_heap`)
  - `from_items(ref List[T])` — build heap from existing list
  - `into_sorted() -> List[T]` — extract elements in sorted order (heap sort)
  - `contains(T) -> Bool` — O(n) membership check
  - `extend(ref List[T])` — bulk push multiple elements
- **`MinHeap[T]`** — min-heap variant (smallest element first): `new`, `push`, `pop`, `peek`, `contains`
- **`SemaphoreGuard`** (`std::sync::semaphore`) — RAII guard with automatic release on drop
  - `acquire_guard()` — blocking acquire returning guard
  - `try_acquire_guard() -> Maybe[SemaphoreGuard]` — non-blocking variant

## Fixed (Compiler)

- **`@derive(Reflect)` size/align** — `TypeInfo` now reports correct `size` and `alignment` via LLVM constant expressions. Previously both were hardcoded to 0.
- **`black_box` intrinsic** — new C++ intrinsic using inline asm with memory clobber; prevents optimizer from eliminating benchmark code
- **`spin_loop_hint` intrinsic** — new C++ intrinsic emitting x86 PAUSE instruction
