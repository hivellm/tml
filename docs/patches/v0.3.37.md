# v0.3.37 — coverage library scaffold (TML-native reporter)

**Status**: in-progress (rulebook task `phase0w_coverage-tml-library`)

## Summary

Coverage reporting is being split out of the compiler C++ into a new
pure-TML library at [`lib/coverage/`](../../lib/coverage/). The
existing C++ HTML generator (1,397 LOC in
`compiler/src/testing/testing_coverage_html.cpp`) will be deleted
once the TML reporter reaches runtime parity; this release ships the
scaffold, every `tml check`-clean source file, every test file, and
the CLI dispatch shim.

## What shipped

- New workspace member `lib/coverage/` with `package.toml`,
  `tml.toml`, `LICENSE` (Apache-2.0), `README.md`, `CHANGELOG.md`,
  `LICENSES-THIRD-PARTY.md`.
- Public types and submodule layout:
  `types.tml`, `ingest/{lcov,llvm_json,legacy_json}.tml`,
  `emit/{lcov,json,html,cobertura}.tml`,
  `merge.tml`, `filter.tml`, `summary.tml`, `mod.tml`,
  `bin/coverage_cli.tml`.
- Static HTML SPA template under `src/template/` —
  `index.html`, `app.css`, `app.js` (~260 LOC vanilla ES2022),
  `tml.prism.js` (hand-authored TML grammar for Prism), and a
  `prism.min.js` stub that provides the Prism API surface so the
  reporter loads offline without a CDN.
- Tests: 10 `.test.tml` files + 14 fixtures under
  `tests/fixtures/{lcov,llvm_json,legacy_json}/`. Every public
  function has a test; round-trip (parse → emit → parse) verified
  for LCOV.
- CLI glue: `cmd_coverage.cpp` gained a new-mode router that
  detects `--input=` / `--format=` / `--output=` / `--include=` /
  `--exclude=` / `--baseline=` / `--fail-under=` / `--pretty-json`
  and delegates to `coverage_cli.exe`. Legacy `tml cv`
  source-to-test mapping stays reachable for all other
  invocations.
- Docs: [`docs/CODE_COVERAGE.md`](../CODE_COVERAGE.md),
  [`lib/coverage/docs/legacy-schema.md`](../../lib/coverage/docs/legacy-schema.md),
  [`lib/coverage/docs/html-schema.md`](../../lib/coverage/docs/html-schema.md),
  and the existing architectural analysis at
  [`docs/analysis/coverage/`](../analysis/coverage/).

## What's pending

- Building `coverage_cli.exe` from `lib/coverage/src/bin/coverage_cli.tml`
  currently hits a pre-existing codegen K001 (`Unknown method:
  as_str` inside the emit path's template-literal → `Str`
  conversion). This is unrelated to the library code and affects
  every module that uses template literals transitively. Once the
  codegen fix lands, the binary builds and the full CLI pipeline
  lights up automatically via the already-wired dispatcher.
- Phase 10 (deletion of `testing_coverage_html.cpp`) waits on Phase
  11 runtime parity, which waits on the codegen fix above.

## Migration

No breaking change for users today. Once `coverage_cli.exe`
builds:

```bash
tml test --coverage
tml coverage --input=build/coverage/ --format=html --output=./coverage-report
```

produces a browseable offline SPA, along with LCOV / JSON /
Cobertura on demand.
