# v0.2.12 — PostgreSQL test infrastructure + codegen fixes

**Date:** 2026-04-04

## Highlights

- **Test runner: build.tml package support** — `tml test` now auto-detects and runs `build.tml` scripts for external packages, enabling tests that depend on native libraries (e.g., libpq for PostgreSQL)
- **PostgreSQL tests** — comprehensive `@test` suite with `DATABASE_URL` env var support (industry-standard connection string pattern)
- **Codegen fix: RawPtr unsized type** — `as RawPtr` in lowlevel blocks no longer generates invalid LLVM IR
- **Test timeout increase** — per-test watchdog raised from 100ms to 10s, with `--per-test-timeout=<ms>` CLI flag

## Changes

### Compiler

- **Test runner: build.tml integration** (`testing_compile.cpp`)
  - Scans module registry for non-standard package imports
  - Auto-runs `build.tml` scripts to resolve link libraries and search paths
  - Copies native artifacts (DLLs) to test cache directory
  - External packages like `postgresql` now link correctly via `tml test`

- **Per-test timeout** (`testing_coordinator.hpp`, `cmd_test.cpp/hpp`)
  - Default raised from 100ms (100,000μs) to 10s (10,000,000μs)
  - Added `--per-test-timeout=<ms>` CLI flag for user customization
  - Suite-level timeout default raised from 20s to 30s

### Codegen fix

- **RawPtr unsized type** (`connection.tml`, `statement.tml`)
  - `as RawPtr` inside lowlevel blocks generated `alloca %struct.RawPtr` without a type definition → LLVM "Cannot allocate unsized type" error
  - Fix: removed all `as RawPtr` casts — `Str` and `*Unit` are already `ptr` at LLVM level
  - Affected: `ptr_offset`, `ptr_read`, `ptr_write`, `mem_free` calls in postgresql package

### PostgreSQL package

- **Parse error fix** — renamed variable `base` to `base_ptr` (`base` is a reserved TML keyword)
- **Test suite** (`pg_connect.test.tml`) — 6 `@test @slow_test` connection lifecycle tests
  - `database_url()` reads from `DATABASE_URL` / `PG_TEST_CONNSTR` env vars (industry standard)
  - URI format: `postgresql://user:pass@host:port/db`
  - Tests: connect, bad host, close, server_version, raw_handle, transaction_status
- **Removed** `pg_integration.tml` (standalone `main()` anti-pattern)
