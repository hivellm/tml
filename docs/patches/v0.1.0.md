# TML v0.1.0 — 2025-12-22

## Summary

Initial release of the TML language — compiler, core/std libraries, test framework, and VSCode extension.

---

## Added

- **TML Compiler** — lexer, parser, type checker (Hindley-Milner), borrow checker (NLL), LLVM codegen via LLVM C API
- **Core Library** — fundamental behaviors: `Clone`, `Eq`, `Ord`, `Hash`, `Display`, `Debug`
- **Standard Library** — collections (`List`, `HashMap`, `Buffer`), file I/O, networking, threading, JSON
- **Test Framework** — `@test` decorator, polymorphic assertion functions (`assert_eq`, `assert_true`, etc.)
- **Backtrace Library** — stack trace capture and symbol resolution for panic messages
- **CLI** — `tml build`, `tml run`, `tml test` commands
- **VSCode Extension** — syntax highlighting for `.tml` files
