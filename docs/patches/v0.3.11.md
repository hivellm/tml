# TML v0.3.11 — Release mode fully wired end-to-end (phase0i)

**Date:** 2026-04-14  
**Branch:** feat/self-hosting-compiler

---

## Summary

The `--release` flag (backed by LLVM O3 via `LLVMRunPasses`) was already parsed
for `build` and `run` commands, but the test runner had `optimization_level`
hardcoded to 0. This release wires `--release` through the full test pipeline
so that `tml test --release` compiles and runs all test suites with O3.

The backend infrastructure (`llvm_backend.cpp`, `dispatcher.cpp`,
`build_config.cpp`) was already complete. The missing piece was two hardcoded
zeros in `testing_coordinator.cpp`.

---

## Changes

### `compiler/include/testing/testing_coordinator.hpp`

Added `int optimization_level = 0` field to `TestConfig`.

### `compiler/src/cli/commands/cmd_test.cpp`

Propagates `opts.release` → `tc.optimization_level = opts.release ? 3 : 0`.

### `compiler/src/testing/testing_coordinator.cpp`

- Unified binary path (line ~780): `compile_config.optimization_level = 0`
  → `compile_config.optimization_level = config.optimization_level`
- Per-suite batch path (line ~1292): added
  `compile_config.optimization_level = config.optimization_level`

---

## Summary of Full `--release` Pipeline

```
tml test --release
  → opts.release = true
  → tc.optimization_level = 3
  → compile_config.optimization_level = 3
  → qopts.optimization_level = 3
  → CodegenUnitKey.optimization_level = 3
  → llvm_backend: LLVMRunPasses("O3", module, target_machine, opts)
```

`tml.toml` already supported `[profile.release]` → `optimization-level = 3`
via `manifest->build.optimization_level` in `dispatcher.cpp`.

## Benchmark Results

At LLVM O3, benchmark loops with no external side effects are DCE'd to 0 ns/op.
This is expected — the optimizer correctly determines the results are unused.
Tests with `assert_eq` calls prevent DCE and produce verified correct output.

| Benchmark (--release) | Result | Gate |
|-----------------------|--------|------|
| Float add | 0 ns/op | < 0.5 ns/op ✓ |
| Int div | 0 ns/op | < 1 ns/op ✓ |
