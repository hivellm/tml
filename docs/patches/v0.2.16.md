# v0.2.16 — Language Documentation Overhaul

**Date:** 2026-04-11

## Summary

Complete synchronization of all language documentation with the actual compiler implementation. Grammar, lexical spec, RFCs, PEG grammar, tree-sitter grammar, and VS Code extension all updated to reflect the current state of TML as implemented in the self-hosting parser and C++ backend.

## Changes

### Lexical Specification (`docs/specs/02-LEXICAL.md`)
- **Keyword count**: 57 → 70 reserved words
- **Added keywords**: `is`, `volatile`, `move`, `throw`, `xor`, `shl`, `shr`, `enum` (alias for `type`), `union`, `var`, `life`, `dyn`
- **Added operators**: `?.` (optional chaining), `|>` (pipe forward), `++`/`--` (increment/decrement), `=>` (match arm), `..` (range/spread), `${` (splice)
- **Updated precedence table**: 13 → 16 levels, includes `as`/`is`, pipe, optional chaining, postfix operators

### EBNF Grammar (`docs/specs/03-GRAMMAR.md`)
- **Complete rewrite** to match actual parser
- **`extend` → `impl`**: Fixed the syntax from `extend Type with Behavior` to `impl Behavior for Type` (matching actual parser)
- **Added**: `let-else`, optional chaining `?.`, pipe forward `|>`, `throw`, `lowlevel` blocks, `async`/`lowlevel` function modifiers, when guards (`if` in match arms), struct field visibility, `as`/`is` type operations, `++`/`--` postfix, `move` closures, `where` clauses on impl blocks
- **Removed documented-but-unimplemented features**: ternary `? :` operator, `catch` expressions, `loop (var i: I32 < N)` variable-declaration loop syntax
- **Fixed match arm arrow**: `->` → `=>` in when expressions

### PEG Grammar (`docs/grammar/tml.peg`)
- **Version**: 0.1.0 → 0.2.0
- Fixed match arm separator from `->` to `=>`
- Added `var` statements, `let-else`, `while` loops, `namespace` declarations
- Added `throw`, `lowlevel` blocks, `await` (prefix form), `move` closures
- Added optional chaining (`?.`), `++`/`--`, `|>` pipe, `is` type check
- Added `null` literal, `where` clauses, doc/module comments
- Updated keyword list to all 70 reserved words
- Added `union` declarations

### Tree-sitter Grammar (`docs/grammar/tree-sitter-tml/`)
- **grammar.js**: Added `var_stmt`, `while_expr`, `throw_expr`, `lowlevel_expr`, `await_prefix_expr`, `pipe_expr`, optional chaining operators, `++`/`--`, `is` type check, `move` closures, block-form `if` expressions, `let-else` with `else` block, `async`/`lowlevel` function modifiers, `where` clauses
- **highlights.scm**: Added all missing keywords (35+ new entries), OOP modifier keywords as separate scope, new operators (`|>`, `?.`, `++`, `--`)

### RFC Index (`docs/rfcs/INDEX.md`)
- RFC-0002 (Syntax): Draft → **Active**
- RFC-0004 (Errors): Draft → **Active** (Outcome/Maybe/`!` all implemented)
- RFC-0005 (Modules): Updated description, capabilities clarified
- RFC-0014 (OOP): Namespace support marked ✅ Complete

### Overview Spec (`docs/specs/01-OVERVIEW.md`)
- Fixed all `extend` examples → `impl`
- Fixed match arm `->` → `=>`
- Updated loop syntax examples (old `loop item in items` → `for item in items`)
- Fixed `String` → `Str` in behavior examples

### VS Code Extension (`vscode-tml/syntaxes/tml.tmLanguage.json`)
- Removed stale keywords: `catch`, `module`, `import`, `extend`, `public`, `unsafe`
- Added missing keywords: `throw`, `move`, `union`, `life`
- Fixed keyword categorization

## Impact

All language documentation now accurately reflects the TML language as implemented in the compiler. This eliminates confusion for both human developers and LLM agents working with TML code.
