# v0.3.49 — C-frontend parses pointer-returning function definitions (phase0z residual)

**Date**: 2026-05-03
**Branch**: feat/self-hosting-compiler
**Task**: phase0z_cc-driver-essential-c-residual (item 5.1.b)
**Predecessor**: v0.3.48 (phase24h, parenthesized-declarator SIGSEGV fix)

## Summary

`cc_driver` rejected every C function definition whose return type
involved a pointer with the parse error
`cc_driver: parse failed at ...:N: expected ';' after declaration`.
The minimal repro is just five tokens:

```c
void* f(void) { return (void*)0; }
```

Failed deterministically (5/5 runs, exit 1) at column 15 (the `{`).
The construct appears 30+ times in `compiler/runtime/core/essential.c`
(every `TML_EXPORT void* …(…)` declaration), gating the residual
self-compile blocker tracked since phase24g.

## Root cause

C declarator semantics: in `*f(void)`, the `*` binds **looser** than
the `(void)` function suffix, so `f` is "a function returning pointer
to T", not "a pointer to function returning T". To get the latter you
write `(*f)(void)` (with parens around the pointer).

`cp_parse_declarator_inner` in `compiler-tml/src/cc/parser.tml` builds
the declarator AST in the natural parsing order:

1. Strip leading `*`s (`ptr_quals`).
2. Parse the direct-declarator (which builds the `Func(Ident, params)`
   suffix internally).
3. Wrap the result with `Pointer(...)` layers in reverse order.

For `void *f(void)` this yields the AST
`Pointer(Func(Ident("f"), [void]))` — the outermost AST layer is
`Pointer`, even though semantically `f` is a function.

The function-definition guard at `cp_parse_top_decl:1711` only
recognized declarators whose **outermost** AST layer was `Func`:

```tml
func declarator_is_func(d: CDeclarator) -> Bool {
    when d {
        Func(_) => return true,
        _ => return false   // ← Pointer(Func(...)) returned false here
    }
}
```

so it fell through to the variable-declaration path, called
`cp_expect_punct(p, Semi, "expected ';' after declaration")`, hit the
`{` opening the body, and reported the parse error at the `{` column.

The same gap blocked the prototype path (line 1745) for any
pointer-returning function declaration, but those happened to compile
because they end in `;` regardless of which path took them.

## Fix

Two coordinated changes:

### 1. `compiler-tml/src/cc/parser.tml`

`declarator_is_func`, `declarator_func_params`, and
`declarator_func_variadic` now recurse through `Pointer(inner, _)`
layers (the return-type modifiers) before bottoming out:

```tml
func declarator_is_func(d: CDeclarator) -> Bool {
    when d {
        Func(_) => return true,
        Pointer(inner, _) => return declarator_is_func(inner.get()),
        _ => return false
    }
}
```

This correctly classifies:
- `Func(Ident)` — function `f` returning T → true
- `Pointer(Func(Ident))` — function `f` returning T* → true
- `Pointer(Pointer(Func(Ident)))` — function `f` returning T** → true
- `Pointer(Ident)` — variable `p` of type T* → false
- `Func(Pointer(Ident))` — pre-existing case (function-pointer
  variable like `void (*sig)(int);`) — true (unchanged behavior)

`Array(Func(...))` would mean "array of functions" which is invalid C
and was not produced by the parser; falls into the `_` arm and
returns false.

### 2. `compiler-tml/src/cc/lower.tml`

`return_type_of_func_decl` previously assumed `fd.declarator` was
always `Func(part)` and computed the return type as
`apply_declarator(base, part.inner)`. With the parser fix,
`fd.declarator` may now be `Pointer(...Func(part))` for any
pointer-returning function definition, so the return type must
include those pointer layers.

Replaced with a recursive helper:

```tml
func ret_type_through_pointers(env, base_ty, decl) -> CType {
    when decl {
        Func(part) => return apply_declarator(env, base_ty, part.inner.get()),
        Pointer(inner, quals) => {
            let inner_ret = ret_type_through_pointers(env, base_ty, inner.get())
            let boxed = Shared[CType]::new(inner_ret)
            return wrap_qualifiers(CType::Ptr(boxed), quals)
        },
        _ => return apply_declarator(env, base_ty, decl)
    }
}
```

For `void *f(void)`:
- decl = `Pointer(Func(Ident, [void]))`
- Recurse into Pointer: inner_ret = `ret_type_through_pointers(void, Func(Ident))` = `apply_declarator(void, Ident("f"))` = `void`
- Wrap: `Ptr(void)` = `void*`. ✓

For `void **f(void)`:
- decl = `Pointer(Pointer(Func(Ident)))`
- Two Pointer layers each contribute one Ptr wrap → `void**`. ✓

### 3. `compiler-tml/src/cc/types.tml`

`wrap_qualifiers` made `pub` so it can be imported by `lower.tml`.
