# TML v0.2.8 — 2026-04-01

## Summary

Inspector & Diagnostics release: complete Chrome DevTools Protocol integration with WebSocket server, CPU profiler instrumentation, debugger with breakpoints/stepping, heap profiler, console module, flame graph generation, and `tml inspect` terminal debugger. Also includes LSP enhancements (references, rename, workspace symbol), Neovim support, file splits for maintainability, and DWARF debug info for structs/pointers/scopes.

---

## Added (Inspector — Chrome DevTools Protocol)

### WebSocket Server (`compiler/runtime/diagnostics/inspector.c`)

- **RFC 6455 WebSocket server** — HTTP upgrade handshake with embedded SHA-1 + Base64
- **CDP JSON-RPC router** — method dispatch for Runtime, Profiler, Debugger, HeapProfiler, Console domains
- **Background thread** — accept loop with select() timeout, single-client
- **Security** — binds to 127.0.0.1 only (loopback)

### CLI Flags

- `--inspect` — enable inspector on port 9229
- `--inspect-brk` — break before user code (wait for debugger)
- `--inspect-port=PORT` — custom inspector port

### CDP Domains Implemented

| Domain | Handlers | Key Features |
|--------|----------|-------------|
| **Runtime** | enable, disable, evaluate, getProperties, getHeapUsage, callFunctionOn, releaseObject, globalLexicalScopeNames | Object mirror system, expression evaluation, consoleAPICalled + exceptionThrown events |
| **Profiler** | enable, disable, start, stop, setSamplingInterval, startPreciseCoverage, stopPreciseCoverage, takePreciseCoverage, getBestEffortCoverage | consoleProfileStarted/Finished events |
| **Debugger** | enable, disable, getScriptSource, setBreakpoint, setBreakpointByUrl, removeBreakpoint, setBreakpointsActive, pause, resume, stepInto, stepOver, stepOut, evaluateOnCallFrame, setVariableValue, setPauseOnExceptions, setAsyncCallStackDepth, getPossibleBreakpoints | Script tracking (256 files), breakpoint table (256), execution control with paused/resumed events |
| **HeapProfiler** | enable, disable, startSampling, stopSampling, getSamplingProfile, takeHeapSnapshot, startTrackingHeapObjects, stopTrackingHeapObjects, getHeapObjectId, getObjectByHeapObjectId, collectGarbage | V8-format heap snapshot via addHeapSnapshotChunk event |
| **Console** | enable, disable, clearMessages | |
| **Concurrency** | getThreads, getLocks, checkDeadlocks | Thread tracking (64), lock contention (128), deadlock detection |

### `tml inspect` Terminal Debugger (`compiler/src/cli/commands/cmd_inspect.cpp`)

- WebSocket client with RFC 6455 client-side masking
- Launches target with `--inspect-brk`, auto-connects
- REPL commands: `break`, `continue`, `step`, `next`, `out`, `backtrace`, `print`, `locals`, `watch`, `heap`, `profile start/stop`, `commands`, `help`, `quit`
- Colorized source display at breakpoints (ANSI yellow highlight)
- Watch expressions with evaluate-on-display

### `std::inspector` TML Module (`lib/std/src/inspector.tml`)

- `open(port)`, `close()`, `wait_for_debugger()`, `url()`, `is_active()`

## Added (Profiler Enhancements)

### MIR Codegen Instrumentation

- `tml_profiler_enter` / `tml_profiler_exit` calls emitted in every function when `--profile` is used
- Gated by `tml_profiler_is_active()` runtime check — zero overhead when inactive
- Wired through `instrument_profiler` option in build.cpp, parallel_build.cpp, llvm_codegen_backend.cpp

### positionTicks in .cpuprofile

- `position_ticks` map in `CallFrame` struct tracks line-level hit counts
- Emitted as real `positionTicks` array in cpuprofile JSON output

### Flame Graph CLI (`tml profile flamegraph`)

- `tml profile flamegraph input.cpuprofile` — ASCII flame graph
- `tml profile flamegraph input.cpuprofile -o output.svg` — SVG flame graph
- Interactive SVG with tooltips, dark theme
