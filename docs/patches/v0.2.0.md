# TML v0.2.0 — 2026-03-19

## Summary

Major release. Query-based incremental compilation, embedded LLVM/LLD (50x test speedup), THIR layer, Polonius borrow checker, 35+ new stdlib modules, async network stack with HTTP/2 + WebSocket, and comprehensive runtime migration away from C.

---

## Highlights

- **Query-Based Compilation** — Demand-driven pipeline (like rustc) with cross-session incremental caching via Red-Green fingerprint coloring. Near-instant rebuilds when source is unchanged.
- **Embedded LLVM + LLD** — In-process IR-to-object compilation and linking. Zero subprocess spawning. Full test suite: ~15 min → ~17 seconds (50x improvement).
- **Zig CC as Default Compiler** — Zig CC (Clang 20.1.2 + bundled LLD) replaces MSVC for building the TML compiler itself.
- **THIR Layer** — Typed HIR between type checking and MIR with advanced trait solver, numeric coercion insertion, and pattern exhaustiveness checking.
- **Polonius Borrow Checker** — Alternative Datalog-style borrow solver (`--polonius`); strictly more permissive than NLL.

## Added (Standard Library — 35+ new modules)

- **`std::http`** — Full HTTP/1.1 server and client with radix-tree router, TLS, cookies, multipart, middleware
- **`std::crypto`** — SHA-1/256/512, AES-GCM, ChaCha20-Poly1305, RSA, ECDSA, Ed25519, X.509 certs, DH/ECDH key exchange
- **`std::zlib`** — Deflate, Gzip, Brotli, Zstd compression/decompression
- **`std::sqlite`** — SQLite3 FFI bindings with prepared statements and typed rows
- **`std::regex`** — Thompson's NFA regex engine with capture groups
- **`std::search`** — BM25 full-text search + HNSW approximate nearest-neighbor vector search
- **`std::aio`** — Async I/O event loop (epoll on Linux, WSAPoll on Windows), timer wheel
- **`std::stream`** — Composable async streams with backpressure, buffering, piping
- **`std::math`**, **`std::datetime`**, **`std::os`**, **`std::glob`**, **`std::random`**

## Added (Core Library)

- **Smart pointers** — `Heap[T]` (Box), `Shared[T]` (Rc), `Sync[T]` (Arc) with full Drop/Clone
- **Atomic operations** — `AtomicI64`, `AtomicBool`, `AtomicPtr[T]` with all orderings
- **`@derive` macros** — 7 traits auto-derivable: `Clone`, `Eq`, `Ord`, `Hash`, `Display`, `Debug`, `Reflect`
- **Reflection** — `TypeInfo`, `FieldInfo`, runtime type introspection via `@derive(Reflect)`
- **Arena/pool allocators** — `Arena[T]`, `Pool[T]` for bump allocation and object reuse
- **SIMD intrinsics** — Initial 128-bit vector type infrastructure

## Added (Async Network Stack)

- **Multi-threaded Executor** — Work-stealing executor with N workers, global task queue, graceful shutdown
- **Thread spawn** — `thread::spawn_fn`, `thread::spawn_i64`, `spawn_blocking` with trampoline pattern
- **`AsyncRead`/`AsyncWrite`** behaviors + `AsyncBufReader`/`AsyncBufWriter`
- **`BufferView`** — Zero-copy buffer view for network protocols
- **ALPN** — TLS protocol negotiation via `TlsContext::set_alpn_protocols()`
- **`select2`** — Future combinator for racing two futures
- **`Promise[T]`** — JavaScript-style promises with `resolve`/`reject`/`then`/`catch`/`all`/`race`/`any`
- **`Observable[T]`** — Reactive streams with 8 operators + Subject/BehaviorSubject/ReplaySubject
- **WebSocket RFC 6455** — Full frame codec, masking, SHA-1 handshake
- **HTTP/2 RFC 7540** — Binary frame codec, 10 frame types, stream state machine, connection management
- **HPACK RFC 7541** — Header compression with 61-entry static table, dynamic table, integer/string codec
- **`Controller` behavior** — Route registration pattern for HTTP handlers
- **`@Get`/`@Post`/`@Put`/`@Delete`/`@Patch` decorators** — Full compiler pipeline support; generates `__tml_register_routes()` auto-registration
- **Pipe operator `|>`** — `x |> f` → `f(x)`, `x |> f(a)` → `f(x, a)`, `x |> .method()` → `x.method()`

## Added (Test Infrastructure)

- **Subprocess-based test runner** (Go model) — each suite compiles to its own EXE, run as subprocess
- **NDJSON protocol** — test results streamed from subprocess to coordinator
- **Suite-level filtering** — `--suite core/str` runs only matching modules
- **Coverage via `TML_COVERAGE_FILE`** — no LLVM profiling, no hangs
- **Parallel compilation** — up to 4 concurrent test processes

## Fixed (Codegen)

- **Nested generic monomorphization** — `Poll[Outcome[I64, IoError]]` generated wrong type; fixed `expected_enum_type_` propagation
- **Generic static → container push** — `list.push(T::static_method(42))` emitted unresolved type; fixed type substitution in `infer_expr_type`
- **async/await type mismatch** — state machine codegen produced `i64` where `i32` expected; fixed `AwaitInst` handler
- **Incremental cache staleness** — `compiler_build_hash()` used source file `__DATE__/__TIME__`; now uses compiler binary last-write-time
- **`dyn Behavior` dispatch** — full vtable dispatch across 5 compiler layers; fixed UB in DCE pass
- **`sret` convention for indirect calls** — function pointer calls returning structs were missing sret causing SEGFAULT

## Changed (Runtime Migration)

- **Buffer, List, HashMap** all reimplemented in pure TML (no C backing)
- **6 dead C files deleted** (2,661 lines removed)
- **`string.c` reduced 59%** — string algorithms migrated to TML
- **23 hardcoded sync declares removed** from runtime
- **Float math** migrated from C helpers to LLVM intrinsics

- SSA struct construction via `insertvalue`/`extractvalue` chains (eliminates alloca+store+load)
- Entry-block alloca hoisting
- Nullable `Maybe[T]` optimization — 8 bytes instead of 16
