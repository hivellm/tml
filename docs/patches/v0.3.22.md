# v0.3.22 — std::msgpack (MessagePack Binary Serialization)

**Date:** 2026-04-15
**Branch:** feat/self-hosting-compiler

## Summary

Adds `std::msgpack` module — a pure TML implementation of the MessagePack
binary serialization format. Same data model as JSON but 2-5x smaller on
the wire and faster to encode/decode. Requested by UzDB for their database
client/server binary protocol.

## API

```tml
use std::msgpack::{MsgPackWriter, MsgPackReader}

// Encode a map with two entries
var w: MsgPackWriter = MsgPackWriter::new()
w.write_map_header(2)
w.write_str("name")
w.write_str("TML")
w.write_str("version")
w.write_u64(322 as U64)
let data: Buffer = w.to_buffer()

// Decode
var r: MsgPackReader = MsgPackReader::from_buffer(ref data)
let n: I64 = r.read_map_header()      // 2
let key1: Maybe[Str] = r.read_str()   // Just("name")
let val1: Maybe[Str] = r.read_str()   // Just("TML")
```

## Module Structure

```
lib/std/src/msgpack/
  mod.tml     — module root, public re-exports
  types.tml   — MsgPackType enum, MsgPackError enum
  writer.tml  — MsgPackWriter encoder (Buffer-backed)
  reader.tml  — MsgPackReader decoder (cursor-based)
```

## Encoder (`MsgPackWriter`)

Full MessagePack spec coverage:
- `write_nil()`, `write_bool(Bool)`
- `write_u64(U64)`, `write_i64(I64)` — auto-selects compact encoding
- `write_f32(F32)`, `write_f64(F64)`
- `write_str(Str)` — fixstr/str8/str16/str32
- `write_bin(ref Buffer)` — bin8/bin16/bin32
- `write_array_header(I64)`, `write_map_header(I64)`

## Decoder (`MsgPackReader`)

- `read_nil() -> Bool`, `read_bool() -> Maybe[Bool]`
- `read_u64() -> Maybe[U64]`, `read_i64() -> Maybe[I64]`
- `read_str() -> Maybe[Str]`
- `read_array_header() -> I64`, `read_map_header() -> I64`
- `position() -> I64`, `remaining() -> I64`

Returns `Maybe[T]` instead of `Outcome[T, E]` to avoid LL(1) parser
limitations with the `?` operator in if/else chains.
