# v0.3.38 — self-contained LLVM + version wiring fix

**Released**: 2026-04-18

## Summary

The TML compiler now builds against a locally-compiled LLVM submodule
without any environment variables, external installs, or PATH tweaks.
The version string shown by `tml --version` finally reflects the real
`/VERSION` file.

## Changes

### Build infrastructure

- **`scripts/build-llvm.bat` / `scripts/build-llvm.sh`** — one-shot
  bootstrap that builds `src/llvm-project/llvm` into `build/llvm/`
  (X86 target only, lld, no clang, no tests/examples/docs,
  DIA SDK off, LIBXML2/ZLIB/ZSTD off). Uses MSVC by default because
  Zig CC against the MSVC target can't cleanly link LLVM's libSupport
  (POSIX-API mismatches in `raw_ostream`/`Path.cpp`).
- **`scripts/build-llvm-ar.bat`** — builds just the `llvm-ar` tool
  on demand (main LLVM build leaves `LLVM_BUILD_TOOLS=OFF` for speed;
  `llvm-ar.exe` is needed by TML's runtime archiver).
- **`scripts/verify-bootstrap.bat`** — end-to-end check: deletes the
  stale CMake cache, rebuilds the TML compiler without `LLVM_DIR`,
  confirms everything wires up.
- **`compiler/CMakeLists.txt`** —
  - `find_package(LLVM CONFIG QUIET HINTS "${CMAKE_SOURCE_DIR}/../build/llvm/lib/cmake/llvm")`
    discovers the local build automatically.
  - `LLVM_LIB_PATHS` adds `build/llvm/lib` at the top (Ninja
    single-config layout) and drops the hard-coded `F:/LLVM/lib`
    escape hatch.
  - `TML_LLVM_HAS_AARCH64` detection — gates the AArch64
    target library list and the compile-time definition so a
    lean X86-only local LLVM builds cleanly.
- **`compiler/src/backend/llvm_backend.cpp`** — `LLVMInitializeAArch64*`
  prototypes and calls are `#ifdef TML_LLVM_HAS_AARCH64`-guarded.
- **`compiler/src/backend/lld_linker.cpp`** — appends
  `build/llvm/bin/` to the linker search path so `lld-link.exe` is
  found after a fresh bootstrap.

### Version wiring

- **`VERSION`** bumped from `0.3.36` → `0.3.38` (skipping `.36` and
  `.37` — those numbers were reserved but never cut a build that
  shipped a real binary).
- **`compiler/src/launcher/main_launcher.cpp`** now includes
  `version_generated.hpp` and uses `tml::VERSION` instead of a
  hard-coded `#define TML_VERSION "0.1.6"` fallback. `tml --version`
  and `tml --help` both print the real number now.
- **`compiler/CMakeLists.txt`** adds
  `${CMAKE_CURRENT_BINARY_DIR}/include` to the launcher's include
  path so it can find the CMake-generated header.

### Codegen

- **`compiler/src/codegen/llvm/expr/infer.cpp`** — adds a
  `TemplateLiteralExpr` case to `LLVMIRGen::infer_expr_type`
  returning `NamedType{"Text"}`. Without this, method dispatch for
  `` `…`.as_str() `` and every other `Text` method on a
  template-literal temporary would emit "Unknown method: as_str" at
  codegen time, even though the type checker correctly typed the
  literal as `Text`.
- **`compiler/src/codegen/mir_codegen.cpp`** — fixes invalid IR
  emission in the shared preamble: `!str_len_range = !{i64 0, …}`
  now correctly uses anonymous metadata `!1 = !{i64 0, …}` (named
  metadata must reference nodes, not contain literals inline); 6
  `!range !str_len_range` references updated accordingly. Removed
  dangling `!alias.scope !str_hdr_scope` / `!noalias !str_data_scope`
  attachments — the scopes were declared for removal in 2024 but
  their use sites in `str_append` were left behind.

### Toolchain

- **`cmake/toolchains/zig.cmake`** — switched to `/MT` (static CRT)
  via `-Xclang --dependent-lib=libcmt` so the TML compiler links
  cleanly against LLVM static libs (which are built `/MT`).

## Breaking changes

None for TML-language users. The developer workflow changes are:

- **First-time setup now requires `scripts\build-llvm.bat`** (~30–90
  minutes). Skipping it and pointing at an external LLVM still works
  via the manual `LLVM_DIR` env var, but is no longer the documented
  path.
- The hard-coded `F:/LLVM/lib` fallback was removed from the CMake
  search; set `LLVM_DIR` explicitly if you relied on it.

## Verified

- Fresh checkout + `scripts\build-llvm.bat` + `scripts\build.bat`
  builds the compiler with zero environment variables.
- `tml --version` prints `tml 0.3.38 (modular)`.
- `tml run hp2.tml --stage=parser:cpp` prints `hello` and exits 0.
- `tml run lib/coverage/src/bin/coverage_cli.tml --stage=parser:cpp --help`
  prints the coverage CLI usage.
