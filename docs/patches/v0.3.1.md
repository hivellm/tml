### CLI

- **`tml cv [path]`** — test coverage report for any TML project
  - Reads `tml.toml` to scope to a specific project
  - Scans `src/**/*.tml` and `tests/**/*.test.tml` automatically
  - Counts `@test` functions per file
  - Maps source modules to test files by checking imports
  - Groups results by subsystem with per-subsystem coverage %
  - Lists untested modules
  - Alias: `tml coverage`
