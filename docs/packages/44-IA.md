# TML Standard Library: AI/ML — Tensor and Neural Networks

> `std::ia` — Complete machine learning library with tensors, automatic differentiation, neural network layers, optimizers, and training infrastructure.

> **Implementation Status (2026-04-04)**: 34 source files, 140 tests, covering tensor operations, autograd with 17 gradient functions, 8 activation functions, 5 loss functions, SGD and Adam optimizers with schedulers, and full training infrastructure.

## Overview

The `std::ia` package provides all tools needed to build and train neural networks. It includes:
- **Tensor Core** — multi-dimensional arrays with NumPy-style broadcasting
- **Autograd Engine** — tape-based reverse-mode automatic differentiation
- **Neural Network Layers** — Linear, Embedding, Dropout, Normalization, Attention
- **Optimizers** — SGD, Adam/AdamW with gradient clipping and scheduling
- **Training Infrastructure** — DataLoader, Checkpoints, loss tracking

### Gradient Functions (17 implemented)

Automatic differentiation supports gradients for:
- **Arithmetic**: ADD, SUB, MUL, DIV, NEG, POW
- **Activation**: RELU, SIGMOID, TANH
- **Matrix**: MATMUL
- **Reduction**: SUM, MEAN
- **Activations**: SOFTMAX, CROSS_ENTROPY
- **Others**: EXP, LOG, SQRT

Example:

```tml
use std::ia::autograd::*
use std::ia::tensor::*

func main() {
    let x = randn(List[I64] { 2, 3 })
    var v = Variable::new(x)
    v.enable_grad()

    let y = mul(ref v.tensor, ref v.tensor)
    var y_var = Variable::new(y)
    y_var.enable_grad()

    backward(mut y_var)

    // Gradients are accumulated
}
```

## Complete Example: MNIST Classification

```tml
use std::ia::tensor::*
use std::ia::autograd::*
use std::ia::nn::*
use std::ia::optim::*
use std::ia::train::*

func main() {
    // Create dataset
    var dataset = Dataset[Tensor, Tensor]::new()
    // ... add MNIST data ...

    // Create model
    var linear1 = Linear::new(784, 128)
    var linear2 = Linear::new(128, 10)

    // Create optimizer
    var opt = SGD::new(ref params, 0.01)
        .with_momentum(0.9)

    // Create dataloader
    var loader = DataLoader[Tensor, Tensor]::new(ref dataset, 32)
        .with_shuffle()

    // Training loop
    for epoch in 1..10 {
        loader.reset()
        var epoch_loss = 0.0

        when loader.next_batch() {
            Just(batch) => {
                for (x, y) in batch {
                    // Forward pass
                    var hidden = linear1.forward(ref x)
                    hidden = relu(ref hidden)
                    var logits = linear2.forward(ref hidden)

                    // Loss
                    var loss = cross_entropy_loss(ref logits, ref y)
                    epoch_loss = epoch_loss + loss.get_f64(0)

                    // Backward pass
                    opt.step()
                }
            },
            Nothing => {},
        }

        println(`Epoch {epoch}: loss = {epoch_loss}`)
    }
}
```

## Performance

- **Tensor operations**: Optimized for NumPy-style broadcasting
- **SIMD**: Leverages SSE2 for float operations (F64x2.get codegen bug temporarily limits SIMD usage)
- **Batching**: Efficient with buffer-backed tensors
- **Backward pass**: Tape-based reverse-mode for memory efficiency

---

## Known Limitations

- **F64x2 codegen bug**: `extractelement` generates i64 index instead of i32. SIMD temporarily disabled for element-wise ops and reductions.
- **Closure codegen bug**: Lambda expressions don't emit in LLVM IR. All ops use explicit loops.
- **Module-level constants**: Don't resolve cross-module. Use functions as workaround.
- **`base` keyword**: Reserved; cannot use as variable name.
