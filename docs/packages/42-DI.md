# TML Standard Library: Dependency Injection

> `std::di` — Zero-copy pointer-based dependency injection without IoC containers or reflection overhead.

## Overview

TML's DI system uses raw pointers for service registration and resolution. There is no IoC container, no reflection, no proxy layer. Services are plain types. Wiring is explicit pointer assignment. Startup overhead is zero, and runtime overhead is a single MOV instruction (1ns) per dependency lookup.

## Import

```tml
use std::di
use std::di::registry::ServiceRegistry
use std::di::module::Module
use std::di::application::{AppConfig, bootstrap_modules, ApplicationInfo}
use std::di::config::InjectedConfig
```

---

## Design Philosophy

### Why Pointers Instead of a Container

| Feature | NestJS | CMMV | TML |
|---------|--------|------|-----|
| Mechanism | IoC + reflect-metadata + proxy | Singleton registry + manual ctor | Raw pointer assignment |
| Startup cost | ~15ms | ~1ms | ~0ns |
| Runtime overhead per call | ~50ns (proxy deref + map lookup) | ~10ns (registry lookup) | ~1ns (single MOV) |
| Memory | Instance + proxy + metadata | Instance + registry entry | Instance + 8-byte pointer |
| Learning curve | Decorators + container concepts | Manual wiring | Direct pointer assignment |

TML's approach is:
1. **Explicit** — you can see exactly where services point to
2. **Zero-cost** — no reflection, no container logic, no indirection
3. **Simple** — just raw pointers in a HashMap

## Core Types

### ServiceRegistry — Service Storage

Stores services as raw pointers (I64) keyed by string tokens:

```tml
pub type ServiceRegistry {
    // internal: HashMap[Str, I64]
}

extend ServiceRegistry {
    /// Creates an empty registry
    pub func new() -> ServiceRegistry

    /// Registers a service with a token
    pub func provide(mut this, token: Str, service_ptr: I64)

    /// Resolves a service by token
    pub func resolve(ref this, token: Str) -> Maybe[I64]

    /// Checks if a service exists
    pub func has(ref this, token: Str) -> Bool

    /// Returns the number of registered services
    pub func len(ref this) -> I64

    /// Clears all services
    pub func clear(mut this)
}
```

### Basic Usage

```tml
use std::di::registry::ServiceRegistry

// Define a service
type DatabaseService {
    connection_string: Str,
}

func main() {
    // Create an instance on the stack
    var db_svc = DatabaseService { connection_string: "sqlite:memory" }

    // Register as pointer
    var reg = ServiceRegistry::new()
    reg.provide("database", ref db_svc as I64)

    // Resolve and use
    when reg.resolve("database") {
        Just(ptr) => {
            let db = (ptr as ref DatabaseService)
            println(db.connection_string)
        },
        Nothing => println("Service not found"),
    }
}
```

## Module — Service Grouping

A `Module` groups service providers and controller registrations. Built with a fluent API.

```tml
pub type Module {
    // internal fields
}

extend Module {
    /// Creates a new module with a name
    pub func new(name: Str) -> Module

    /// Registers a service provider
    pub func provide(mut this, token: Str, service_ptr: I64) -> Module

    /// Registers a controller
    pub func controller(mut this, path: Str, handler_ptr: I64) -> Module

    /// Resolves a service
    pub func resolve(ref this, token: Str) -> Maybe[I64]

    /// Returns the count of registered services
    pub func service_count(ref this) -> I64

    /// Returns the count of registered controllers
    pub func controller_count(ref this) -> I32

    /// Returns the module name
    pub func name(ref this) -> Str
}
```

### Usage

```tml
use std::di::module::Module

type UserService {
    name: Str,
}

type ApiController {
    svc: ref UserService,
}

func main() {
    var user_svc = UserService { name: "Alice" }
    var ctrl = ApiController { svc: ref user_svc }

    var m = Module::new("app")
        .provide("user_service", ref user_svc as I64)
        .controller("/users", ref ctrl as I64)

    println(`Services: {m.service_count()}`)  // => Services: 1
    println(`Controllers: {m.controller_count()}`)  // => Controllers: 1
}
```

## Application Bootstrap

`bootstrap_modules` accepts a config and a module, counts topology, and returns an `ApplicationInfo`.

```tml
pub type ApplicationInfo {
    // internal fields
}

extend ApplicationInfo {
    /// Returns a summary string
    pub func summary(ref this) -> Str
}

pub func bootstrap_modules(config: AppConfig, module: ref Module) 
    -> ApplicationInfo
```

### Usage

```tml
use std::di::application::{AppConfig, bootstrap_modules}

func main() {
    let config = AppConfig::new(3000).with_cors("*")
    let info = bootstrap_modules(config, ref my_module)
    println(info.summary())
    // => "Application: 2 services, 1 controllers, port 3000"
}
```

## Application Config

### AppConfig — Configuration Builder

```tml
pub type AppConfig {
    // internal fields
}

extend AppConfig {
    /// Creates a new config with a port
    pub func new(port: I64) -> AppConfig

    /// Enables CORS with an origin
    pub func with_cors(mut this, origin: Str) -> AppConfig

    /// Returns the configured port
    pub func port(ref this) -> I64

    /// Returns the CORS origin, if set
    pub func cors_origin(ref this) -> Maybe[Str]
}
```

### Usage

```tml
use std::di::application::AppConfig

func main() {
    let config = AppConfig::new(8080)
        .with_cors("https://example.com")

    println(config.port())  // => 8080
    when config.cors_origin() {
        Just(origin) => println(`CORS: {origin}`),
        Nothing => println("CORS disabled"),
    }
}
```

## Configuration Store

### InjectedConfig — Key-Value Config

A simple string-based key-value store with typed accessors:

```tml
pub type InjectedConfig {
    // internal: HashMap[Str, Str]
}

extend InjectedConfig {
    /// Creates an empty config
    pub func new() -> InjectedConfig

    /// Sets a string value
    pub func set(mut this, key: Str, value: Str)

    /// Gets a string value
    pub func get(ref this, key: Str) -> Maybe[Str]

    /// Gets with a default
    pub func get_or(ref this, key: Str, default: Str) -> Str

    /// Gets as I64
    pub func get_i64(ref this, key: Str) -> Maybe[I64]

    /// Gets I64 with a default
    pub func get_i64_or(ref this, key: Str, default: I64) -> I64

    /// Gets as Bool
    pub func get_bool(ref this, key: Str) -> Maybe[Bool]

    /// Checks if a key exists
    pub func has(ref this, key: Str) -> Bool

    /// Returns the number of entries
    pub func len(ref this) -> I64

    /// Clears all entries
    pub func clear(mut this)
}
```

### Usage

```tml
use std::di::config::InjectedConfig

func main() {
    var cfg = InjectedConfig::new()
    cfg.set("port", "3000")
    cfg.set("debug", "true")
    cfg.set("cors_origin", "*")

    let port = cfg.get_i64_or("port", 8080)  // => 3000
    let cors = cfg.get_or("cors_origin", "")  // => "*"
    let debug = cfg.get_bool("debug")  // => Just(true)
    let has_key = cfg.has("port")  // => true
}
```

## Complete Example

A minimal REST API with DI:

```tml
use std::di::registry::ServiceRegistry
use std::di::module::Module
use std::di::application::{AppConfig, bootstrap_modules}
use std::di::config::InjectedConfig
use std::http::server::{HttpServer, IncomingMessage, Response}

type UserService {
    db_connection: Str,
}

func list_users(req: IncomingMessage, res: Response) -> Str {
    return res.json("[{\"id\":1,\"name\":\"Alice\"}]")
}

func main() {
    // Create service instance
    var user_svc = UserService { db_connection: ":memory" }

    // Build module with DI
    var m = Module::new("app")
        .provide("user_service", ref user_svc as I64)
        .controller("/users", list_users as I64)

    // Bootstrap application
    let config = AppConfig::new(3000).with_cors("*")
    let info = bootstrap_modules(config, ref m)
    println(info.summary())

    // Start HTTP server
    var server = HttpServer::new(3000)
    server.get("/users", list_users as I64)
    server.listen()
}
```

## Patterns

### Singleton Services

Store service instances in module-level statics:

```tml
static var USER_SERVICE: UserService

func init_user_service() {
    USER_SERVICE = UserService { name: "Alice" }
}

func main() {
    init_user_service()
    var m = Module::new("app")
        .provide("user_service", ref USER_SERVICE as I64)
}
```

### Factory Functions

Use factory functions to create services:

```tml
func create_database_service() -> DatabaseService {
    return DatabaseService { connection_string: ":memory" }
}

func main() {
    let db = create_database_service()
    var m = Module::new("app")
        .provide("database", ref db as I64)
}
```

### Service Composition

Compose services in the module:

```tml
func main() {
    var auth_svc = AuthService { secret: "key123" }
    var user_svc = UserService { auth: ref auth_svc }

    var m = Module::new("app")
        .provide("auth", ref auth_svc as I64)
        .provide("user", ref user_svc as I64)
}
```
