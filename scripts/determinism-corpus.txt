# phase26f 1.4 canary (F-022 container field-drop): removing the drop.cpp
# container leak special-case now drops container struct fields. This is the
# DOUBLE-FREE direction — a container-bearing struct passed by value to a METHOD
# arg (the fact-side safe-fallback blind spot) must NOT double-free the inner
# List buffer once the field drop fires. Under the gate's poison+quarantine a
# double-free becomes a crash (nonzero exit); correct = exit 0. (The LEAK
# direction is verified out-of-band via scripts/fixtures/container_field_leak_probe.tml,
# whose residual is only observable through the debug leak reporter, not an exit code.)
tml_container_field_methodarg: ./build/debug/bin/tml.exe run scripts/fixtures/container_field_methodarg_probe.tml

# phase26f 1.5 canaries (conditional-move drop-flag elaboration): a binding moved
# on SOME control-flow paths but not all is now marked conditionally_moved by the
# checker and guarded by a runtime drop flag instead of static suppression. Three
# LEAK-direction shapes (the move's guard is false at runtime, so the binding must
# still be dropped) + one DOUBLE-FREE-direction shape (the move IS taken, so the
# binding must NOT be dropped again). All run via `tml run` (AST codegen — where
# drop flags live). Correct = witness strong_count == 1 → exit 0.
