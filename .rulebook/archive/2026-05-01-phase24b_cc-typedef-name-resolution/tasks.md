## 2. Root cause
- [x] 2.1 Real cause is a value-pass + drop-glue interaction, not a return-path codegen bug: `base_to_ctype(env: CTypeEnv, b: CBaseType)` and the rest of the type-system entry points took `env` by value. `CTypeEnv` is a struct of four `HashMap` fields whose `buckets` pointers are heap-allocated. The bitwise copy at the call site means the callee's local `env` aliases the caller's `buckets` allocation; on exit, drop glue runs on the local copy and `mem_free`s the buckets, leaving the caller's `lw.env.typedefs.buckets` dangling. The next `base_to_ctype` call (the second function parameter, in the `int32_t add(int32_t a, int32_t b)` reproducer) re-enters the freed bucket array and crashes on the `Heap.get()` deref.
- [x] 2.2 Synthetic-token tests do not exercise the lowerer, only the parser, which is why they pass while the full `tml cc` pipeline crashes.

## 3. Fix (option A from proposal — `ref CTypeEnv` everywhere)
- [x] 3.1 Regression test landed at `compiler-tml/tests/native/c_frontend.test.tml::test_phase24b_base_to_ctype_typedef_repeat` — registers a `int32_t -> int` typedef, then calls `base_to_ctype` three times in a row on the same env, mirroring `lower_func_decl`'s parameter loop. Pre-fix the second call would have crashed; post-fix all three return `CT_KIND_INT`.
- [x] 3.2 Selected option (a) from `proposal.md` — change every type-system entry point to take `env: ref CTypeEnv`, eliminating the value-copy + drop-glue path. This is the surgical TML-side fix; the alternative (codegen elides field-level drops on a value-passed local) is a larger codegen refactor that remains a long-term backlog item separate from this task.
- [x] 3.3 Applied to `compiler-tml/src/cc/types.tml`: `base_to_ctype`, `apply_declarator`, `resolve_type_name`, `sizeof_type`, `sizeof_heap`, `alignof_type`, `alignof_heap`, `size_for_kind`, `layout_struct`, `layout_union`, `ptr_add_scale` — 11 signatures + matching internal forwards (`ref env`).
- [x] 3.4 Updated all callers in `compiler-tml/src/cc/lower.tml` (13 sites — `lower_struct_def`, `lower_union_def`, `lower_typedef`, `lower_global_var`, `lower_func_decl` parameter loop, `return_type_of_func_decl`, `lower_local_decl`) plus the regression test to pass `ref lw.env`.
